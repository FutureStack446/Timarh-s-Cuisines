# Timarh’s Cuisines

A premium, mobile-responsive web platform for **Timarh’s Cuisines**, showcasing luxury artisanal pastries, bespoke cakes, and gourmet catering services. This project features a modern "Glassmorphism" design aesthetic and a seamless user experience across all devices.

## ✨ Features

-   **Glassmorphism UI**: A sophisticated look using backdrop filters, translucent surfaces, and refined typography.
-   **Fully Responsive Design**: Hand-tuned CSS breakpoints ensure the site looks perfect on everything from small smartphones to large desktops.
-   **Interactive Menu**: Dynamic filtering and search functionality for different food categories (Cakes, Donuts, Savouries, etc.).
-   **Visual Gallery**: A Masonry-style image grid featuring a custom-built lightbox for viewing high-resolution pastry designs.
-   **Smooth Animations**: Implementation of Intersection Observer API for scroll-reveal animations and custom CSS keyframes for a premium feel.
-   **Direct WhatsApp Integration**: Floating action buttons and direct order links to streamline the customer ordering process.
-   **Performance Optimized**: Lightweight Vanilla JavaScript and optimized CSS with no heavy external dependencies.

## 🛠️ Tech Stack

-   **HTML5**: Semantic structure and SEO-friendly markup.
-   **CSS3**: Custom properties (CSS variables), Flexbox, CSS Grid, and advanced animations.
-   -   **Vanilla JavaScript**: ES6+ logic for filtering, modals, carousels, and scroll interactions.
-   **Font Awesome**: Vector icons for a sharp look on retina displays.
-   **Google Fonts**: Fraunces for elegant headings and Inter for clean body text.

## 🚀 Getting Started

To view the project locally:

1.  Clone the repository:
    ```bash
    git clone https://github.com/FutureStack446/Timarh-s-Cuisines.git
    ```
2.  Navigate to the project folder.
3.  Open `index.html` in any modern web browser.

## 📂 Project Structure

-   `index.html`: The high-impact landing page.
-   `home.html`: Main dashboard/overview.
-   `about.html`: Brand story and founder information.
-   `menu.html`: Interactive product catalog.
-   `gallery.html`: Visual showcase of creations.
-   `contact.html`: Inquiries and location details.
-   `style.css`: The core design system and responsive logic.
-   `script.js`: Interactive features and UI logic.
